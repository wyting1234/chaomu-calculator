📱 Android 安装步骤

  1. 点击上方按钮或扫码下载 APK
  2. 打开下载的安装包，提示「未知来源」时选择允许
  3. 安装完成后桌面出现「朝暮计」图标，全屏运行

🍎 iPhone 使用方式

  1. 用 Safari 打开本页，点「在线使用」
  2. 点分享按钮 → 「添加到主屏幕」
  3. 桌面图标即可全屏使用（无需开发者账号）

数据保存在设备本地（localStorage），清除应用数据会丢失记录。APK 与签名密钥已备份于 GitHub 仓库 wyting1234/chaomu-calculator。
